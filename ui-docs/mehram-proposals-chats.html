Mehram — Proposals and Chats

What happens after Send proposal, the Proposals tab in both directions, and the chat with both walis present.

What "Send proposal" actually does

It is not a like. It is a formal request that travels through two families before a single message can be sent.

Send proposal

→

PR1. Optional note to her wali.
→
Sent
PR2. Confirmation.
→
Proposals tab
PR3. Status tracked here.
Then it moves through four stages, in this order: your wali approves → her wali reviews → she decides → chat opens with both walis. Each stage is visible to both sides. Nobody is left wondering where it went, which is the single biggest complaint families have about existing rishta apps.
Receiving is free. A user can see and decline an incoming proposal without a membership. Charging someone to find out that a proposal arrived is a hostage mechanic and families will describe it that way.
Declines are silent and final. No reason field, no notification of who declined at which stage, no re-proposing for 90 days. The sender sees only "not taken forward".
